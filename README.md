# PW 29 – Notifiche NIS2 al CSIRT Italia

Project work PW 29, L-31 Informatica per le Aziende Digitali, Università Telematica Pegaso.

Applicazione web full stack in Java per la redazione e la gestione delle notifiche di incidente significativo (D.Lgs. 138/2024) da trasmettere al CSIRT Italia, con classificazione secondo la Tassonomia Cyber ACN.
